RustBB APT repository

The rustbb package for Debian and Ubuntu, amd64 and arm64, signed by the key 8A5C 916C 2231 973F 4D69 F84D 675A 145E BCF4 5CC2. To add it and install RustBB:

sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSLo /etc/apt/keyrings/rustbb.gpg https://rustbb.github.io/apt/rustbb.gpg
printf 'Types: deb\nURIs: https://rustbb.github.io/apt\nSuites: stable\nComponents: main\nSigned-By: /etc/apt/keyrings/rustbb.gpg\n' |
  sudo tee /etc/apt/sources.list.d/rustbb.sources
sudo apt update && sudo apt install rustbb

Upgrades come with apt upgrade. With Xenia's repository added too, sudo apt install rustbb xenia-server sets up the forum and the web server in front of it. Deployment says what the package sets up.
